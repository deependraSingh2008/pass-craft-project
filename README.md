# PassCraft – Password Suggestion Tool

PassCraft is a simple desktop application built with **Python and Tkinter** that helps users generate random passwords through an easy-to-use graphical interface.

## Features
- Generate random passwords of a user-defined length.
- Copy generated passwords to the clipboard.
- Clear the input and reset the interface.
- Validate password length (1–256 characters).
- Simple, dark-themed graphical user interface.

## Technologies Used
- Python
- Tkinter
- Random module
- Clipboard functionality

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

```bash
python pass_frontend.py
```

## Learning Outcomes
This project demonstrates Python fundamentals, GUI development, input validation, and event handling.

## Future Improvements
- Use Python's `secrets` module for stronger password generation.
- Add options to customize password characters.
- Add password strength indicators.

**Note:** This project is intended for learning purposes. For real-world password security, use a cryptographically secure generator.
